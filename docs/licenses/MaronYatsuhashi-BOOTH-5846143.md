  retargeted, or modified.
- Source and public copies must remain byte-identical and are pinned by
  SHA-256 in `scripts/verify-assets.mjs`.
- The file is registered as both a standalone Studio animation and a Live
  Moments performance.

  copied, or committed.

  `Golden-Wheatlight-Original.mp3`. It was generated with Gemini Pro/Lyria 3,

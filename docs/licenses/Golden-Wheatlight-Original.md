## Authorship and source

This is a first-party dance soundtrack created for this project on 2026-07-26.
It is synthesized deterministically by
`scripts/generate-uimugi-music.mjs`. The generator defines the chord voicings,
original lead phrase, eighth-note bass, sixteenth/thirty-second-note percussion
and arpeggios, kick syncopation, snare rolls, drops, stabs, pads, riser,
arrangement, stereo placement, dynamics, and final fade.

No commercial audio recording, melody file, loop, lyric, or sample is imported.
The deterministic noise used for percussion is generated from the fixed seed
`0x6d2b79f5`.

The arrangement borrows only high-level dance-production ideas from the two

and a countdown into the drop. It does not reuse their words, melody, vocal
performance, or audio bytes. VieNeu model and preset terms still apply to the
generated vocal stems.

The MP3 bitstream is encoded with `lamejs` 1.2.1, distributed under LGPL-3.0.
The encoder is an installed development dependency and is not bundled into the
web application's runtime JavaScript.

## Reproduction and verification

```powershell
npm run generate:original-music
npm run verify:original-music
npm run verify-assets
```

The first command recreates the exact MP3. The verification commands compare
the generated bytes and canonical SHA-256 so an accidental soundtrack change
cannot silently enter a build.
